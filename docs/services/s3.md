# 🪣 Simple Storage Service (`s3`)

> The infinite object store where every byte of your data lake begins.

- **Category:** Storage
- **Service id:** `s3`

## Why it exists
Nearly everything on AWS touches S3: backups, sites, lakes, model artifacts. 11 nines of durability.

## When to use it
Object storage, data lake landing zone, static hosting, ML data.

## Learn first

- Buckets, keys, prefixes
- Storage classes & lifecycles
- Bucket policies vs IAM
- Versioning & public-access block

## Terraform
```hcl
resource "aws_s3_bucket" "assets" { bucket = "acme-assets-prod" }

resource "aws_s3_bucket_public_access_block" "assets" {
  bucket = aws_s3_bucket.assets.id
  block_public_acls = true; block_public_policy = true
  ignore_public_acls = true; restrict_public_buckets = true
}

resource "aws_s3_bucket_versioning" "assets" {
  bucket = aws_s3_bucket.assets.id
  versioning_configuration { status = "Enabled" }
}
```

## AWS CDK
```ts
import * as s3 from "aws-cdk-lib/aws-s3";
const bucket = new s3.Bucket(this, "Assets", {
  versioned: true,
  blockPublicAccess: s3.BlockPublicAccess.BLOCK_ALL,
});
```

## Boto3 (Python)
```python
import boto3
s3 = boto3.client("s3", region_name="us-east-1")
s3.upload_file("report.pdf", "acme-assets-prod", "2026/08/report.pdf")
s3.download_file("acme-assets-prod", "2026/08/report.pdf", "out.pdf")
```

## Delete / teardown
```python
s3.delete_object(Bucket="acme-assets-prod", Key="2026/08/report.pdf")
```

## Expert tips

- Block ALL public access; serve sites via CloudFront OAC instead.
- Bucket names are global across all AWS accounts.

## Real-world example

**Netflix** — Stores the master copy of every title it streams.
