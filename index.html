02 / HOW THEY TALK TO EACH OTHER

The five architectures you'll build in real jobs.

Services are useless in isolation. This is how organizations wire them — VPC-to-VPC, API routing, event fan-out, the DevOps loop, and the GenAI/AgentOps path.

FLOW 01

The production web request

DNS → EDGE → COMPUTE → DATA
Route 53DNS
CloudFront310+ edge PoPs
ALBTLS ends here
Auto Scaling2–40 EC2
RDS Multi-AZprivate subnet
Why this order: DNS resolves first, the edge caches static assets, the ALB terminates TLS and only forwards dynamic calls.
Security layering: EC2 and RDS live in private subnets — nothing on the internet reaches them directly.
Failure story: health checks mark instances unhealthy, Auto Scaling replaces them, Multi-AZ fails the DB over automatically.
FLOW 02

Serverless API — API Gateway → Lambda → DynamoDB

AUTH → ROUTE → EXECUTE → STORE
CognitoJWT auth
API GatewayPOST /orders
Lambdabusiness logic
DynamoDB<10ms reads
Routing: API Gateway matches POST /orders, validates the Cognito JWT, invokes Lambda, returns its JSON.
IAM is the wire: Lambda assumes an execution role whose policy allows exactly one table — no credentials files.
Async side-channel: Lambda publishes to EventBridge → SQS workers + SNS; the API response never waits.
FLOW 03

VPC-to-VPC & hybrid connectivity

ON-PREM ⇄ CLOUD · VPC ⇄ VPC
On-prem DCyour racks
Direct Connectprivate fiber
Transit Gatewayhub & spoke
VPC-A / VPC-Bper team · per env
2 VPCs: use VPC Peering (cheap, direct, non-transitive). 5+ VPCs: use Transit Gateway — one hub, every spoke.
Private SaaS access: PrivateLink exposes a service into another account's VPC without the public internet.
Hybrid: Direct Connect gives a dedicated line; the TGW makes every attached VPC reachable from on-prem via BGP.
FLOW 04

The MLOps / DevOps pipeline

COMMIT → BUILD → DEPLOY → OBSERVE
CodePipelinegit push
CodeBuildbuild / train
ECRimage / model
SageMakerblue/green
CloudWatchdrift alarms
MLOps: Step Functions retrains on schedule, the registry versions models, endpoints deploy blue-green — rollback is one click.
Gate everything: CodeBuild runs tests + Inspector scans; failures stop the pipeline before shipping.
Observe: CloudWatch watches latency & model drift; EventBridge re-triggers the build stage on alarm.
FLOW 05

The GenAI / AgentOps request path (RAG)

GROUND → FILTER → REASON → OBSERVE
API Gatewaychat request
Bedrock Agentplans + acts
Guardrailsin/out filter
Knowledge BaseRAG retrieval
OpenSearchvector index
Grounded answers: the agent retrieves from the Knowledge Base (S3 docs chunked + embedded) so answers cite your data.
Guardrails both ways: input filters block jailbreaks/PII; output filters block harmful content before users see it.
AgentOps loop: aliases (DRAFT→PROD) enable rollback; every trace, tool call & latency lands in CloudWatch for evals.
